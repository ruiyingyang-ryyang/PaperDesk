# PaperDesk V1.0.0

[源码仓库](https://github.com/ruiyingyang-ryyang/PaperDesk) · [下载 V1.0.0](https://github.com/ruiyingyang-ryyang/PaperDesk/releases/tag/v1.0.0) · [问题反馈](https://github.com/ruiyingyang-ryyang/PaperDesk/issues)

Windows 11 论文筛选、AI 问答与辅助写作工作台。应用内不显示版本号；支持原生贴靠、浅色/夜间模式和字号调整。

## 安装与更新

退出旧版托盘中的 PaperDesk，运行 `PaperDesk-Windows-x64-Setup.exe`。安装采用静默模式，不弹出 Setup 进度窗口，完成后启动应用。日常使用桌面或开始菜单的 PaperDesk 快捷方式。也可直接运行 `dist/PaperDesk-win32-x64/PaperDesk.exe`，需保留同目录的其他文件。

保留已有功能和数据格式，支持覆盖更新。新版本启动时统一窗口、任务栏、托盘、桌面及开始菜单快捷方式的应用标识和图标，并更新指向 PaperDesk 的已有任务栏固定快捷方式。图标位于 Windows 可直接读取的独立 ICO 文件中，避免从应用归档读取和复用旧图标缓存。

## 导航和显示

- 工作台：论文筛选、每周推送、快速检索。检索设置、推送设置、运行记录为同级入口。
- 英文 Arial，中文使用系统中文字体；图标旁的 PaperDesk 品牌标题使用 45° 蓝紫青渐变色，夜间自动切换为更明亮的配色，采用随包附带的 Libre Bodoni 粗体衬线字体，呈现接近 Nature 杂志的风格，其他电脑无需额外安装字体。统一字号和行高。配色参考 DeepSeek Harness：白色工作区、浅灰侧栏、黑白对比主按钮与克制的蓝色交互点缀，夜间主题使用分层深灰。选中项不加粗外框。卡片统一 12px 圆角，普通按钮及输入控件统一 8px 圆角；标题、正文、标签与注释按统一字号层级显示。年月选择采用与其他按钮一致的应用内选择器。
- 论文筛选、每周推送、全部论文和星标收藏均可收起上方工具栏，将更多空间留给阅读；统计、筛选和按周导出控件可随时展开。每个板块分别记住收起状态，重启后保留。正在运行任务的进度和停止入口仍保持可见。
- 顶部提供夜间模式、问题反馈、API 余量、字号、重新开始和语言入口。点击“问题反馈”先展示[作者 GitHub 主页链接](https://github.com/ruiyingyang-ryyang)，询问是否跳转，并提示“访问 GitHub 可能需要科学上网。”；选择“确认跳转”后才在系统默认浏览器打开主页，可联系作者；窄窗口显示图标并保留悬停提示。字号滑条拖动时立即更新全界面并保存，范围 11–20；设置页移除重复入口。EN / 中使用地球图案，测试连接按钮使用双箭头。
- 保留 Win11 原生窗口标题栏及贴靠功能。最小窗口 420 × 420，窄窗口保留左侧缩略结果和右侧详情；最大字号亦可使用。
- 不提供内嵌学术网页、Google 登录、网页收录、测试桌面通知或补全元数据按钮；仍保留真实推送通知与自动元数据读取。

## 论文筛选

在检索设置保存关键词及自命名词组、期刊、页数、作者条件、发表年月范围和 SerpApi 密钥。关键词最多 3 组、每组 5 个词或短语，组内 AND，组间合并。名称与对应关键词整合在同一块区域，编辑名称后立即更新并自动保存，无需点击“保存设置”；关键词内容和其他检索条件仍需保存设置。检索设置与推送设置的名称分别保存，并同步更新结果筛选项。示例使用空间光通信、大气湍流、捕获与跟踪；关注期刊示例为 Journal of Lightwave Technology 和 Journal of Optical Communications and Networking。起止年月均可留空；设置范围后按月包含边界月份，缺少发表月份的候选排除。旧版年份范围迁移为对应起始年 1 月至结束年 12 月。

检索设置、推送设置和临时按作者检索均支持多个作者姓名、多个学校/机构（选填），用分号或换行分隔，各最多 10 个；匹配任一作者与任一机构。支持第一作者/通讯作者/任一角色。仅填写姓名也可检索，不限制学校时可能包含同名作者。论文筛选页面另有临时的“按作者检索”。优先核对 OpenAlex 作者标识、机构及论文中的明确作者角色；无法确认身份或角色的候选不作为作者检索匹配结果。姓名跨语言写法、重名和历史机构可能限制结果，不承诺穷尽作者的所有论文。

先自动读取 Crossref、OpenAlex 及必要的出版方声明信息，再展示结果。左侧卡片含标题、同一行的通讯作者与第一作者、下一行的年份与期刊，以及通讯单位。通讯单位从已明确标注的通讯作者的机构信息中读取，详情页同时显示；未公开的信息标注“来源未提供”，不使用“待核验”，也不猜测通讯作者或机构。收藏按钮使用与侧栏相同的星形图案。

点击论文后在右侧阅读详情和论文原始链接。详情面板日间采用纯白底色，夜间切换中性深灰；标题完整换行，过长内容可滚动阅读，不用省略号截断。检索来源已经截短的标题，会在 DOI 或出版页面身份核对成功后读取完整标题，来源无法确认时保留原始信息。左侧筛选命中的文字在详情中高亮。完整摘要自动显示；清理开头误摘录的 Abstract / 摘要标题，升级时也清理已有摘要。仅提供 EN / 中 / DS 三种摘要模式；原语言直接显示，翻译和通俗解释通过 DeepSeek 完成并缓存。完整摘要缺失时明确提示，不用检索片段冒充摘要。

## DeepSeek 和 API

在设置填写自己的 DeepSeek / SerpApi 密钥并保存。Windows DPAPI 加密保存密钥，应用及设备重启后可继续读取。支持测试两个服务的连接；SerpApi 通过账户接口查询可用次数，不执行论文搜索，不展示账号邮箱。顶部“API 余量”可查看并刷新 DeepSeek 的实际货币余额及 SerpApi 剩余检索次数，使用官方只读接口，不调用付费对话。查询失败时显示错误，不猜测余额；只展示余额与币种，不暴露密钥、邮箱或账户身份。

快速检索支持连续问答、停止回答、历史保存与问题重命名。在“历史问题”搜索框输入名称或提问内容，实时筛选已保存的对话；支持中文、英文大小写忽略和空格分隔的多个关键词，也会搜索同一对话中的后续问题。结果显示匹配问题摘要，点击可定位到问题；点击清空或按 Escape 恢复列表。搜索在本机进行，不调用 API。空白对话顶部与 DeepSeek 同一行显示“提问”，下方“从一个问题开始”加粗显示。鼠标移入时整条历史记录/按钮改变底色；长标题使用省略号，提示可查看完整标题，问题正文完整换行显示。可选择删除整条对话，或只删除某个问题及其对应回答；均提供取消/确认，正在回答的对话需先停止。回答和译文支持 Markdown 加粗、标题、列表、表格、代码，以及行内/独立 LaTeX 公式：`\(...\)`、`\[...\]`、`$...$`、`$$...$$`。公式字体和渲染器随包提供，不执行模型返回的 HTML 或脚本。

DS 使用提示词：“用通俗易懂的语言解释论文研究对象和研究内容，输出结果。”并要求用日常比喻辅助理解，说明比喻对应的概念与适用边界，不把比喻当作论文结论。支持 DeepSeek Flash / DeepSeek V4 Pro，保留超时、停止、鉴权及余额错误提示。快速问答基于模型知识，不自动搜索实时互联网。

## 每周推送

推送设置独立保存关键词、词组名、期刊、页数和作者条件，不受一般检索的发表年月设置影响。可选择每周几、几点几分推送，默认周五 08:00，按本机时区执行；修改已启用的推送时间并保存后，同步更新系统定时任务。“立即检查推送”使用相同规则运行一次。

**只推送实际推送日期前 7 个完整自然日发表的论文，不含推送当天。**例如 2026-11-06 推送只包含 2026-10-30 至 2026-11-05 发表的论文。只有年份、只有年月、缺失或无效的完整发布日期都不满足推送条件；更早的论文不会补推。错过定时推送后恢复运行时，也以实际执行日期计算窗口。

已推送过的论文通过持久化发送记录去重；即使运行日志已裁剪、论文后续补充 DOI 或再次一般检索，也不会重复推送。工作台“每周推送”按实际推送周（周一至周日）归纳，已读后仍保留。旧版每周论文和可确定的推送时间自动迁移；没有可恢复日期的早期记录单列显示，不伪造日期。

可按周、推送起止日期选择范围，再勾选论文，使用“归纳并批量导出 MD”。选择保存文件夹后，每周生成一个 `weekly-YYYY-MM-DD.md`，另附 `index.md` 目录。默认使用 DeepSeek 归纳研究主题，附原文摘要、作者、期刊及论文链接；也可关闭 AI，按周导出原始资料，不调用 API。大批量内容分批归纳并保留引用编号。取消或 API 错误不会留下不完整的 AI 导出批次。每次导出创建独立目录，不覆盖以前导出的文件。

Windows 定时任务要求用户已登录、电脑开机且联网；关机期间无法准时推送。手动检查不会把未来任务标记为已执行。数据清空后原推送去重历史也会清除，这是“重新开始”的一部分。

## 数据与重新开始

数据默认在 `%APPDATA%\PaperDesk\library.json`，保存时保留 `.bak`。设置中保存的 API 密钥不出现在公开页面状态及 JSON/CSV 备份中。JSON 备份包含论文、作者标注、收藏、标签、译文、对话和推送关联。

顶部的“重新开始”需再次确认。它会清空本机论文、收藏、标签、译文、运行记录、每周记录、设置和对话，停用定时推送，并清理应用自己的恢复快照；保留加密 API 密钥和连接模型，不更改服务商账户、用量、账单，也不删除已经导出的文件。运行检索、问答或导出期间不能清空，需先结束任务。本交付只在隔离测试数据中验证此功能，没有对用户研究库执行清空。

升级保留旧论文和密钥；卸载默认保留研究库。API 服务自身的历史、配额与费用由服务商管理。

## 分享给其他电脑

- **安装方式**：只需发送 `PaperDesk-Windows-x64-Setup.exe`，接收方在 Windows 11 x64 电脑上运行即可。
- **便携方式**：复制完整的“便携版”文件夹，再运行其中的 `PaperDesk.exe`。单独复制这个主程序会缺少依赖文件。
- 本次交付的安装包、便携版和源码不含个人应用资料或设置中保存的 API 密钥。密钥通过 Windows 当前用户安全存储加密，保存在个人应用数据目录，接收方首次使用须填写自己的密钥。
- 请勿分享 `%APPDATA%\PaperDesk` 个人资料目录。自己在聊天、标签或文档中手动粘贴的秘密属于普通内容，分享这些资料前需自行移除。
- 打包及交付流程会检查个人资料、浏览器缓存、日志、环境文件、常见明文密钥格式和当前账户已保存的凭据标记，发现后停止交付。JSON 备份只导出论文与对话，不导出密钥存储。

## 构建与验证

需要 Node.js 22.12+：

```powershell
npm ci
npm test
npm run test:desktop
npm run test:chat-search
npm run build:win
```

运行时无第三方 Node 依赖。Markdown、净化器及公式库作为本地前端资源提供。`package:win` 只打包 `src`、`assets`、README、许可证及必要应用信息，排除开发工具、测试档案和密钥。可设置 `PAPERDESK_ELECTRON_ZIP_DIR` 使用已缓存的 Electron 压缩包。安装器使用 NSIS，默认静默安装。

自动测试覆盖持久化、论文与作者筛选、日期范围、每周推送、写作提示词、历史问题搜索及资料隔离。桌面检查使用隔离资料库和模拟 API，不消耗真实付费密钥；截图输出到 `screenshots-current/`。打包产物写入 `dist/`，安装包写入 `release/`。

桌面检查默认启动源码应用；可设置 `PAPERDESK_TEST_EXE` 为打包后的 `PaperDesk.exe` 完整路径，验证发行版本。`test:release` 需先执行 `build:win`。

## GPT 与辅助写作

检索设置增加 GPT (OpenAI) 密钥、模型和当前 AI 接口选择。快速写作分类中的辅助写作支持多个目标期刊、自定义写作类型、左右文段对照、复制与取消；输入上限 30000 字符。期刊和类型自动保存，原文和结果在运行期间保留。论文解释 DS 标识统一为 AI，已读未星标论文在结束当前阅读后隐藏，不删除记录。

GPT 采用官方 Chat Completions 接口，使用 max_completion_tokens，不发送 DeepSeek 专用参数。接口参考：https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create 。GPT 模型名称由用户按账户权限填写。测试连接发送一条简短请求。

验证：node --test test/*.test.cjs；node scripts/verify-writing.cjs（使用独立资料库与模拟 API 响应，不产生真实 API 费用）。


## 辅助写作调整

写作类型固定为期刊、会议、学位论文，采用应用统一样式的下拉框。期刊名称用英文分号分隔，默认提供 Nature Communications、Nature Photonics、Journal of Lightwave Technology 三个可多选标签；点击标签添加，再次点击取消，也可手动填写其他期刊。删除写作类型下方说明及底部自动保存备注。

辅助写作页面可独立选择 GPT (OpenAI) 或 DS (DeepSeek)，使用检索设置中已保存的对应密钥和模型。写作选择不更改问答等其他功能的接口；期刊、类型和接口在生成时保存。原文和结果在页面切换时保留。


## 润色、翻译与侧边栏调整

辅助写作操作改为“润色 / 翻译 / 润色与翻译”三个按钮，分别使用独立提示词。润色保留原文语言和原意，参考所选期刊的语言表达风格，要求行文连贯、通顺、符合学术规范，表达自然、克制，避免模板化 AI 套话。翻译忠实保留内容，不额外进行风格性改写；润色与翻译将译文润色后只输出最终版本。翻译目标可选英文或简体中文，默认英文。三个操作共用已选择的 GPT/DS 接口。

操作区固定在页面底部，处理期间三个按钮禁用并提供停止功能。侧边栏按工作台、快速写作和文献管理分组，统一按钮高度、间距、图标与文字对齐，适配不同窗口尺寸。


## 写作按钮状态与 Harness 配色

修复润色按钮固定高亮的问题。润色、翻译、润色与翻译的高亮随实际操作切换，运行时保持可辨识，完成、失败或取消后保留选中状态。

统一采用 DeepSeek Harness 官方 design-platform.css 的日夜配色及交互语义，包含主操作、输入框、侧栏、选中标签、菜单、提示与滚动条；面板阴影参考官方 gradient-shadow-text.css。配色集中在 src/harness-palette.css，组件不再单独设近似色。

参考：https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-theme/src/styles/design-platform.css 。后台写作提示词保持不变，软件没有增加提示词展示或编辑入口。


## 每周推送日期选择器

将推送日期起、止的系统日期弹窗改为应用内日期选择器，统一使用 Harness 日间/夜间配色、圆角、月份下拉框与选中状态。支持年份与月份切换、日历选日、清空和取消，保留既有日期筛选与导出范围。


## 全部论文筛选

“全部论文”新增与“星标收藏”相同的全部通讯作者、全部标签下拉筛选，选项涵盖所有已收录论文。支持通讯作者、标签及其他条件组合筛选；星标收藏继续只显示收藏范围内的选项，沿用既有界面样式。
