# PaperDesk 软件功能介绍

本文包含可直接发布的小红书正文、配图文案和空间光通信检索示例。

## 可直接发布的小红书正文

**标题：空间光通信论文这样整理**

做空间光通信，想追踪一个方向的新论文，还要读英文摘要、整理收藏、记下临时想到的问题。

PaperDesk 把这些事情放进一个 Windows 工作台：论文筛选、每周推送、快速检索。界面采用极简风格，白色工作区配浅灰侧栏和蓝色交互点缀，也支持夜间模式和字号调整。

**1｜按自己的研究方向找论文**

设置关键词组、关注期刊和发表年月，也能填写多个作者与机构，筛选其第一作者或通讯作者论文。左侧看标题、作者、通讯单位、年份和期刊，点开后在右侧读完整标题、摘要与原始链接。上方工具栏可以收起，留出更多阅读空间，适合分屏使用。

**2｜关键词组可以自己命名**

例如“空间光通信”“捕获与跟踪”“自适应光学”。名称就在对应关键词上方，修改后自动保存并立即更新筛选项。每组最多 5 个词或短语，最多 3 组。

**3｜英文摘要与中文解读切换**

摘要支持 EN / 中 / DS。DS 会用通俗语言和生活中的比喻解释研究对象与内容；回答支持加粗、列表、表格和公式，译文与解释也会保存。

**4｜每周什么时候收论文，自己决定**

可以设置每周几、几点几分推送。只收录推送日前 7 个完整自然日发表、且未推送过的论文。结果按周归纳，还能选择范围，借助 DeepSeek 整理主题，批量导出 Markdown。

**5｜想到问题就问，之后还能找回来**

快速检索接入 DeepSeek，支持连续问答、历史保存和问题重命名。某个问答不想保留，可以单独删除，也能删除整条对话。

**6｜日常整理也照顾到了**

星标、标签、CSV 导出、JSON 备份，以及 API 余量查询都在。论文库和对话保存在本机，密钥加密保存，重启后可继续使用。

使用前需要自行填写 DeepSeek / SerpApi 密钥，相关服务按各自规则计费，API 功能需联网。AI 解释用于辅助理解；快速问答基于模型知识，不会自动实时检索文献。论文结论仍以原文为准，来源缺失的信息不会猜测补齐。定时推送需要用户已登录、电脑开机联网。

如果你也在做空间光通信，可以从自己的关键词和关注期刊开始，搭一个专属的论文列表。

## 空间光通信检索示例

词组名称可以直接修改，立即生效并自动保存；关键词内容修改后点击“保存设置”。以下是可按研究方向调整的起点，组内关键词同时匹配，组间合并结果。

- **空间光通信**：`free space optical communication, atmospheric turbulence`
- **捕获与跟踪**：`laser communication, acquisition pointing tracking`
- **自适应光学**：`space optical communication, adaptive optics`

关注期刊示例：

- [Journal of Lightwave Technology](https://opg.optica.org/content/journal/about/item/jlt/)
- [Journal of Optical Communications and Networking](https://opg.optica.org/content/journal/about/item/jocn/about)

一般检索可按发表年月限定范围；每周推送单独保存检索条件。例如设置“周三 19:45”，保存后启用推送即可。检索结果受来源覆盖、元数据和 API 配额影响；缺少确切发布日期的论文不进入每周推送。

## 功能概览

- **论文筛选**：关键词、期刊、多作者、多机构、作者身份及发表年月筛选；左右分栏阅读、完整标题、通讯单位、可收起工具栏。
- **摘要阅读**：EN / 中 / DS、通俗比喻解释、Markdown 与公式显示、原始论文链接。
- **每周推送**：自选星期与时间、七日范围、持久去重、按周归档、选择范围归纳并导出 Markdown。
- **快速检索**：DeepSeek 连续问答、历史保存、重命名、删除单个问答或整条对话。
- **文献管理**：星标、标签、已读状态、CSV 导出、JSON 备份与导入。
- **使用体验**：Windows 11 分屏、中英切换、夜间模式、字号调整、API 余量查询、加密密钥记忆、保留密钥的重新开始。
