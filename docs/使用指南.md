# PaperDesk 使用指南

[返回项目主页](../README.md)

## 安装和启动

下载 [V1.0.1 发布页](https://github.com/ruiyingyang-ryyang/PaperDesk/releases/tag/v1.0.1) 的免安装 EXE 或安装包。Windows 11 x64 的运行环境已包含在程序中。

免安装版首次运行自动解压到本机缓存，之后直接打开；安装版静默安装，完成后自动启动。更新前请先退出系统托盘中的旧版本。

## 配置 API

在“检索设置”保存自己的密钥。GPT 与 DeepSeek 分别保存密钥和模型，问答与摘要处理使用所选接口，辅助写作可单独选择接口。

论文自动检索与每周推送使用 SerpApi。Crossref、OpenAlex 等来源用于补全论文信息。API 额度、网络可达性与服务商账户权限会影响结果。

## 论文筛选

最多填写 3 组关键词，每组最多 5 个词或短语；组内同时匹配，组间合并结果。关键词组名称修改后自动保存，其他检索条件修改后需保存设置。

期刊名称每行一个，留空表示不限制。作者与机构支持分号或换行分隔的多个值，各最多 10 个。只有来源明确提供的第一作者或通讯作者身份才用于相应角色筛选。

发表年月范围包含边界月份；缺少发表月份的候选会排除。详情显示标题、作者、通讯单位、期刊、摘要与原始链接，来源缺失的信息会明确标注。

## 问答和历史问题

“快速检索”用于向所选 AI 提问，不会自动检索实时互联网。Enter 发送，Shift + Enter 换行，回答过程中可以停止。

历史问题搜索支持对话名称、首次提问和后续问题正文。英文忽略大小写，多个关键词用空格分隔；点击结果可定位匹配问题。清空输入或按 Escape 恢复完整列表。

可重命名对话，或删除整条对话、某个问题及对应回答，删除前会询问确认。

### 问题与回答导出

点击快速检索上方“导出问题 / 问答”，选择当前对话或全部历史。仅问题可导出 Markdown，问题及回答可导出 Markdown 或含可点击目录、书签的 PDF。导出使用已保存内容，不发起模型请求。

快速检索顶部可独立切换 DS / GPT；回答完成后保留阅读位置。

## 常用论文

在“文献管理 → 常用论文”多选上传本机 PDF，单篇最多 100 MB。修改标题，设置“选题参考 / 写作参考 / 无标签”后点击保存；重点论文可勾选标题标红加粗。

阅读时使用页码、上一页 / 下一页与缩放。选中文字后点击“高亮选文”；扫描件开启“区域高亮”后拖选。三种颜色可选，标注列表支持页码定位与删除。PDF 副本和高亮保存在本机，原文件不改写。

## GPT API 用量

顶部“API 用量与余量”可按本月、近 7 天、近 30 天查看本机调用次数和输入 / 输出 / 缓存 Token（UTC 日汇总）。仅记录 1.0.1 之后收到的 GPT 响应，不包括其他客户端和此前历史。

若需组织官方用量与费用，在检索设置中单独保存有权限的 OpenAI Admin Key。普通 GPT Key 无法进行组织查询；组织费用覆盖全部 API，不代表本机账单或余额。详见 [更新说明](releases/v1.0.1.md#用量统计说明)。

## 辅助写作

1. 选择目标期刊、期刊/会议/学位论文类型，以及 GPT 或 DeepSeek 接口。
2. 粘贴最多 30,000 字符的原文。
3. 选择“润色”“翻译”或“润色与翻译”；翻译目标可选英文或简体中文。
4. 在右侧查看和复制结果，必要时停止处理。

润色保留原意和原文语言，翻译保留内容，组合操作输出最终译文。原文和结果在本次应用运行的页面切换间保留；重要内容请及时另行保存。模型输出需要自行核对事实、术语和数据。

## 每周推送和导出

推送设置与一般检索独立保存。Windows 定时任务按本机时区执行，需要用户已登录、电脑开机并联网。

推送窗口为实际执行日期之前 7 个完整自然日，不含当天。缺少完整发布日期、早于窗口或已推送的论文会排除。

选择周、日期范围和论文，点击“归纳并批量导出 MD”，可按周生成 Markdown 和目录。开启 AI 时调用所选接口，关闭后按原始资料导出。

## 收藏、备份与数据

使用星标和标签整理文献，可按通讯作者和标签组合筛选。数据默认在 `%APPDATA%\PaperDesk`，保存时保留恢复快照。

JSON 备份包含论文、收藏、标签、摘要处理结果、对话、推送关联，以及常用论文 PDF 与高亮标注，排除所有密钥。导入文件上限 700 MB。卸载默认保留研究库；“重新开始”会清空研究资料与设置，并保留已保存的 API 密钥和连接模型。
