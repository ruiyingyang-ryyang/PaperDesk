## 验证边界

自动检查使用模拟检索数据与隔离测试配置，没有调用真实付费检索或模型接口，也未启用用户的定时任务。

当前执行环境未能启动打包后的 Electron 程序（Playwright 返回 `Process failed to launch`），因此最终 Windows 程序的实际启动仍需在正常 Windows 会话中确认。界面交互通过当前 Chrome 验证，源码检索逻辑通过自动检查。

本机缓存的 NSIS 编译器也无法启动（进程创建返回 `UNKNOWN`），本机先生成免安装 ZIP；解压后双击 `Windows-x64/PaperDesk.exe` 使用。GitHub Windows 流程另行构建和检查新版安装 EXE 与免安装 EXE，不使用旧版安装包。

以上为发布前本机验证记录；GitHub 构建、测试与发布结果请以仓库 Actions 和对应 Release 页面为准。
