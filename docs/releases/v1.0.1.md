# PaperDesk V1.0.1

发布日期：2026-11-13。适用于 Windows 11 x64。

## 更新内容

1. **导出快速检索记录**：点击“导出问题 / 问答”，选择当前对话或全部历史。可导出仅问题 Markdown、问题及回答 Markdown，或带可点击目录、PDF 书签的问答 PDF。中文、Markdown 表格和数学公式保留排版；未完成的回答明确标注。导出不调用 AI。
2. **对话内切换 DS / GPT**：使用快速检索顶部“回答接口”选择下一次回答的服务商。密钥仍在检索设置中分别配置，默认摘要与写作接口保持独立，新回答显示实际使用的接口。
3. **常用论文**：在文献管理中上传本机 PDF，可一次选择多个文件，单篇最多 100 MB。按“选题参考”“写作参考”“无标签”分类，勾选“重点论文”后保存，标题显示为红色加粗。支持修改标题、按标题搜索、按标签筛选、页码跳转和缩放。
4. **PDF 高亮**：选中文字后点击“高亮选文”；扫描件开启“区域高亮”后拖选。可选择黄色、绿色、粉色，在标注列表中定位页码或删除标注。标注独立保存在应用内，原始 PDF 不会改写；移动原始 PDF 不影响已导入副本。JSON 备份包括 PDF 副本、标签和标注。
5. **修复阅读位置跳动**：回答完成和界面刷新时保持当前阅读位置，不再跳到最后一行。新提问定位到问题附近，历史搜索仍可定位匹配的提问。
6. **GPT API 用量**：顶部“API 用量与余量”显示本机 GPT 请求次数、输入 / 输出 / 缓存输入 Token。另可在检索设置中保存独立的 OpenAI Admin Key，查询组织 Completions 用量与组织全部 API 费用，并可打开官方用量控制台。

## 布局修正版

修复 PDF.js 全局 `.sidebar` 样式覆盖应用固定导航的问题，恢复侧栏与主内容顶部对齐，消除顶部大块留白。应用仅加载限定在 PDF 页面内的文字选择样式，避免阅读组件影响导航、按钮和空状态。

更新时先从系统托盘退出旧版本，再解压修正版 ZIP 并运行其中的 `PaperDesk.exe`。已有论文、标注与 API 设置保留。

最终完整包同时修正 API 对话框：刷新按钮固定在框内底部右侧，内容过长时只滚动正文；打开、刷新和状态更新始终复用一个对话框，不再重复淡入或叠加显示。连续点击只发起一次查询，关闭后请求完成不会重新打开窗口。

最终完整包包含全部 GitHub 源码、文档、检查与发布脚本，以及 `release/Windows-x64/PaperDesk.exe` 和运行资源。`release/` 已被 Git 忽略；程序二进制作为 GitHub Release 附件发布，不提交到源码分支。

## 用量统计说明

- 本机统计自 1.0.1 开始，只统计此电脑实际收到的 GPT 响应，包括问答、辅助写作、摘要处理、连接测试及 AI 导出归纳。不回填旧版本、其他客户端或未收到结果的请求。响应未提供 usage 时仅计调用次数。
- 本月、近 7 天、近 30 天按 UTC 自然日汇总，包含今天。
- 组织查询使用独立的 Admin Key；普通 GPT API Key 无法访问组织管理接口。管理员密钥加密保存，可单独移除，不用于模型调用，也不会进入备份。
- 组织 Token 指标来自全部模型的 Completions 用量；费用覆盖组织全部 API 和其他客户端，可能有统计延迟。费用不是账户余额，不是本机 GPT 的单独账单。
- [OpenAI Completions 用量接口](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/completions) · [组织费用接口](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs)

## 更新与数据

更新前退出托盘中的旧版本，启动新版。原有研究库和已保存的 API 密钥继续使用。建议先备份；含本地 PDF 的 JSON 可能较大，请不要公开上传。导入备份文件上限为 700 MB。

“重新开始”会清空常用论文副本、高亮标注及本机用量统计，保留已保存的 API 密钥，不改变服务商账单。
