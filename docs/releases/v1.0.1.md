# PaperDesk V1.0.1

发布日期：2026-11-13。适用于 Windows 11 x64。

V1.0.1 基于 V1.0.0（2026-11-11），修正了 5 个影响使用的问题，并新增常用论文、对话导出、对话内接口切换与 GPT 用量统计。本次共新增 224 个文件、修改 20 个文件，其中 206 个为 PDF.js 本地渲染资源。下载与校验值见 [V1.0.1 发布页](https://github.com/ruiyingyang-ryyang/PaperDesk/releases/tag/v1.0.1)。

## 修正

### 1. 侧栏错位与顶部留白

V1.0.0 不包含 PDF 阅读。V1.0.1 加入本地 PDF.js 6.5.438 后，完整查看器样式表里的全局 `.sidebar`、`.empty` 与控件规则覆盖了 PaperDesk 自己的布局，导致左侧导航变为相对定位、主内容整体下移（约 660 px）、顶部出现大块留白，空状态也显示异常。

V1.0.1 不再全局加载完整查看器样式，改为 `src/pdf-text-layer.css` 中限定 `#pdf-sheet` 的文字选择规则，并调整 `index.html` 的样式与脚本顺序。新增 `test/layout-isolation.test.cjs` 与 `npm run test:layout`，在桌面、夜间、大字号和窄屏下检查侧栏固定、内容顶部对齐，且文档没有横向溢出。

### 2. 对话框重叠与反复淡入

V1.0.0 的对话框写在主界面模板里，每次界面重绘都会销毁并重建遮罩与对话框，刷新查询时出现叠加和反复淡入。

V1.0.1 把弹出层移到独立的 `#modal-root`（`src/dialogs.js`）：刷新时只替换对话框内容，复用同一个遮罩，并保留焦点与正文滚动位置；刷新按钮固定在对话框内底部右侧，长内容只滚动正文。

### 3. 长回答跳到底部

V1.0.0 在回答完成或界面刷新后把消息区滚到最后一行，正在阅读的位置被顶走。

V1.0.1 改为按消息位置计算滚动，渲染前记录、渲染后恢复位置；新提问定位到问题附近，历史搜索仍定位到命中问题（`src/ui.js`）。

### 4. 重复查询与关闭后重新打开

V1.0.1 在请求期间禁用发送与刷新入口，连续点击只发起一次查询；关闭对话框后完成的请求不再重新打开窗口（`src/v101.js`、`src/dialogs.js`）。

### 5. 重置与备份未覆盖常用论文

“重新开始”现在同时清除常用论文的本机 PDF 副本与高亮标注，保留 API 密钥；JSON 备份与导入包含常用论文、PDF 与标注，导入上限由 50 MB 提高到 700 MB（`src/main.cjs`、`src/favorite-papers.cjs`）。

## 新增

1. **常用论文**：在文献管理中上传本机 PDF，可一次选择多个文件，单篇最多 100 MB。按“选题参考”“写作参考”“无标签”分类，勾选“重点论文”后标题显示为红色加粗；支持修改标题、按标题搜索、按标签筛选、页码跳转和缩放。
2. **PDF 高亮**：选中文字后点击“高亮选文”；扫描件开启“区域高亮”后拖选。可选三种颜色，在标注列表中定位页码或删除标注。标注保存在应用内，不改写原始 PDF；JSON 备份包含 PDF 副本与标注。
3. **对话导出**：点击“导出问题 / 问答”，选择当前对话或全部历史，导出仅问题 Markdown、问答 Markdown，或带可点击目录和 PDF 书签的问答 PDF。导出读取已保存内容，不额外调用 AI。
4. **对话内切换 DS / GPT**：使用快速检索顶部的“回答接口”选择下一次回答的服务商；密钥仍在检索设置中分别配置，新回答记录实际接口，历史回答保留来源。
5. **GPT 用量统计**：顶部“API 用量与余量”显示本机 GPT 请求次数与输入 / 输出 / 缓存输入 Token；另可保存独立的 OpenAI Admin Key，查询组织 Completions 用量与组织全部 API 费用，支持本月 / 近 7 天 / 近 30 天。

## 更新与数据

更新前先从系统托盘退出旧版本，再运行新的 `PaperDesk-Windows-x64-Setup.exe` 或 `PaperDesk-Windows-x64-Portable.exe`。已有研究库、常用论文、标注与 API 设置继续使用；含本地 PDF 的 JSON 备份可能较大，请不要公开上传，导入上限为 700 MB。

“重新开始”会清空常用论文副本、高亮标注及本机用量统计，保留已保存的 API 密钥，不改变服务商账单。

## 用量统计说明

- 本机统计自 1.0.1 开始，只统计此电脑实际收到的 GPT 响应，包括问答、辅助写作、摘要处理、连接测试及 AI 导出归纳。不回填旧版本、其他客户端或未收到结果的请求。响应未提供 usage 时仅计调用次数。
- 本月、近 7 天、近 30 天按 UTC 自然日汇总，包含今天。
- 组织查询使用独立的 Admin Key；普通 GPT API Key 无法访问组织管理接口。管理员密钥加密保存，可单独移除，不用于模型调用，也不会进入备份。
- 组织 Token 指标来自全部模型的 Completions 用量；费用覆盖组织全部 API 和其他客户端，可能有统计延迟。费用不是账户余额，不是本机 GPT 的单独账单。
- [OpenAI Completions 用量接口](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/completions) · [组织费用接口](https://developers.openai.com/api/reference/resources/admin/subresources/organization/subresources/usage/methods/costs)
